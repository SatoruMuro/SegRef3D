3D Slicerで補間する

SliceBridgeは空白スライスを用意します。形状の補間そのものは、 3D Slicerの Fill between slices で行います。

  1. 01
    Volumeとして読み込む

    Add data → Show Options → Label map を選択

  2. 02
    Segmentationへ変換

    Segmentations → Import labelmap to segmentation

  3. 03
    重なりを許可

    Modify other segments → Allow overlap

  4. 04
    輪郭間を補間

    Segment Editor → Fill between slices → Initialize → Apply
